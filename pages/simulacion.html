Código del circuito simulado

Este es el sketch que controla el LED en la simulación de arriba.

// ===================================
// Blink — LED parpadeante
// Placa: Arduino UNO
// Pin:   13 (LED integrado o externo)
// ===================================

const int PIN_LED = 13;   // pin del LED

void setup() {
  pinMode(PIN_LED, OUTPUT);   // configurar como salida
  Serial.begin(9600);
  Serial.println("Simulacion iniciada...");
}

void loop() {
  digitalWrite(PIN_LED, HIGH);  // encender
  Serial.println("LED: ENCENDIDO");
  delay(1000);                  // esperar 1 segundo

  digitalWrite(PIN_LED, LOW);   // apagar
  Serial.println("LED: APAGADO");
  delay(1000);                  // esperar 1 segundo
}

En el panel, selecciona Circuits y luego haz clic en "Crear nuevo circuito".

Arrastra componentes

Busca "Arduino UNO" en el panel derecho y arrástralo al área de trabajo. Luego agrega LEDs, resistencias, etc.

Haz clic en el Arduino → "Código". Escribe tu sketch y presiona "Iniciar simulación".
