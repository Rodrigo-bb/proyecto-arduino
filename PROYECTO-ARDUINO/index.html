Conceptos

¿Qué es Arduino?

Una plataforma de prototipado electrónico de código abierto que combina hardware y software accesibles para todos.

🖥️

Hardware

Arduino es una placa electrónica con un microcontrolador (ATmega) y pines digitales/analógicos de entrada y salida. Se conecta a la computadora por USB para programarse.

💻

Software (IDE)

El IDE de Arduino permite programar en C/C++ simplificado. Sus dos funciones clave son setup() (se ejecuta una vez) y loop() (se repite infinitamente).

🌍

Comunidad

Más de 30 millones de usuarios en todo el mundo. Proyectos educativos, industriales y artísticos. Documentación oficial disponible en español en arduino.cc.

¿Cómo empezar? — Tus primeros 5 pasos

1
Instala el IDE — Descarga Arduino IDE desde arduino.cc/en/software
2
Conecta tu placa — Usa un cable USB tipo B y selecciona el puerto COM correcto
3
Escribe tu primer sketch — El clásico "Blink" hace parpadear el LED integrado
4
Sube el código — Presiona el botón "→" (Upload) en el IDE
5
¡Mira el resultado! — El LED parpadea. ¡Tu primer programa Arduino funciona!
